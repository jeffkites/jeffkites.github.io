# Jeff Kites

Hunter Wind: https://jeffkites.github.io/wind/

SWGOH dashboard: https://jeffkites.github.io/Swgoh-data/

The wind map's canonical source, parsers, tests and static export are maintained
in [jeffkites/Swgoh-data](https://github.com/jeffkites/Swgoh-data/tree/main/wind).
This user Pages repository serves the same static wind export at the shorter
address. Copy the four generated wind assets here when changing the map.
Live readings refresh directly from the existing read-only Cloudflare service;
GitHub Pages needs no server, credentials or scheduled data rebuild.

The wind map shows all seven coastal gauges together. Site-review maps have
separate Lake Mac/Newcastle, Nelson Bay and Central Coast views. Nineteen numbered site pins open credited guides or the Mawsons Wall / Spoons
nomination awaiting local review. Squids / Squid’s Ink is searchable by its aliases.
The Nelson Bay pins link to Jordan Jensen's original article. Place references
come from OpenStreetMap (ODbL 1.0) and GeoNames (Spoon Rocks, CC BY 4.0)
and identify areas rather than verified launches.

The owner review desk at /wind/#review-desk uses the existing dashboard key.
Drafts stay private; Approve & publish makes your edited notes public with
source credits retained. No private draft or access key belongs in this repository.

Keep this repository public and configure GitHub Pages to deploy `main / (root)`.
Never copy private SWGOH or accounting snapshots into this repository.
The review desk keeps its owner key in memory only; Lock clears it from the page.

Wind arrows, map markers and gauge cards share speed changeovers at 12, 16 and
30 knots (red/yellow/green/brown). Recent speed trends compare timed average
wind readings; gusts remain a separate dashed history series.
